## Step 1：Webの仕組み（クライアント・サーバー）

```
ブラウザ（クライアント）          Flask アプリ（サーバー）
┌─────────────────┐    リクエスト    ┌──────────────────┐
│                 │ ─────────────▶  │                  │
│ URLを入力       │                 │  app.py が動いてる│
│                 │ ◀─────────────  │                  │
│                 │    レスポンス    │                  │
└─────────────────┘                 └──────────────────┘
```

- **クライアント（ブラウザ）**：「ページをください」とお願いする側
- **サーバー（Flask）**：「はい、どうぞ」とHTMLを返す側
- この「お願い→返答」のやり取り = **HTTP通信**

## Step 2：URLの構造

```
http://127.0.0.1:5000/search
 ↑      ↑         ↑    ↑
通信    IPアドレス  ポート パス
方式
```

### IPアドレス（127.0.0.1）
「どのコンピューターか」を示す住所。  
`127.0.0.1` = 自分自身のパソコン（ループバックアドレス）

```
普通のWebサービス → インターネット上のサーバーのIP
開発環境         → 127.0.0.1（自分のパソコンの中）
```

### ポート番号（5000）
「そのコンピューターのどの窓口か」

```
パソコン   = マンション
IPアドレス = マンションの住所
ポート番号 = 部屋番号
```

Flask は `app.run()` でデフォルト5000番を使用。

### パス（/search）
「サーバーの中のどの機能を使いたいか」

```
/          → トップページ
/search    → 蔵書検索
/loan      → 貸出登録
/overdue   → 延滞一覧
```

## Step 3：デコレータ（@）の意味

```python
@app.route("/search")
def search():
    books = models.search_books(...)
    return render_template("search.html", books=books)
```

`@app.route("/search")` = **「/search にアクセスがきたらこの関数を呼んでください」という登録**

```
ブラウザが /search にアクセス
        ↓
Flask が「/search に登録された関数は？」と調べる
        ↓
@app.route("/search") の search() 関数を実行
        ↓
HTML を返す
```

電話の自動応答に似ている：
```
「検索は1番」→ /search = search()
「貸出は2番」→ /loan   = loan()
```

## Step 4：1回のHTTP通信の全体像

```
① ブラウザで http://127.0.0.1:5000/search と入力
        ↓
② 自分のパソコンの5000番ポートにリクエストが届く
        ↓
③ Flask（app.py）が受け取る
        ↓
④ /search に対応する search() 関数を呼ぶ
        ↓
⑤ models.search_books() でDBを検索
        ↓
⑥ search.html にデータを埋め込んでブラウザに返す
        ↓
⑦ ブラウザが HTML を画面に表示する
```

ボタンを押したり、URLを入力するたびにこれが繰り返される。
