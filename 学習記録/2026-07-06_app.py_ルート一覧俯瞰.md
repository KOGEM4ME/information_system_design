## @app.route の基本構造

```
URL が来る → デコレータで関数と紐付く → 関数が処理して画面を返す
```

```python
@app.route("/search")   # 「/search にアクセスがきたら…」
def search():           # 「この関数を実行する」
    ...
    return render_template("search.html", ...)  # 「この画面を返す」
```

---

## 全ルート一覧

| URL | メソッド | やること |
|-----|---------|---------|
| `/` | GET | → /search にリダイレクト |
| `/search` | GET | → 検索・一覧表示 |
| `/loan` | GET | → 貸出フォーム表示 |
| `/loan` | POST | → 貸出登録処理 |
| `/return` | GET | → 返却フォーム表示 |
| `/return` | POST | → 返却登録処理 |
| `/overdue` | GET | → 延滞一覧表示 |
| `/admin/books` | GET/POST | → 蔵書一覧・新規登録 |
| `/admin/books/delete/<id>` | POST | → 蔵書削除 |
| `/admin/members` | GET/POST | → 利用者一覧・新規登録 |
| `/admin/members/delete/<id>` | POST | → 利用者削除 |

---

## 気づくパターン

- **「見るだけ」** → GET のみ（`/search`, `/overdue`）
- **「登録・変更・削除」** → POST を含む
- **「フォーム + 処理」** → 同じURLで GET/POST を分岐

```python
@app.route("/loan", methods=["GET", "POST"])
def loan():
    if request.method == "POST":
        # フォーム送信 → 処理する
        ...
        return redirect(url_for("loan"))   # PRGパターン（二重送信防止）
    # GET → フォームを表示するだけ
    return render_template("loan.html", ...)
```

## パスパラメータ（削除系ルート）

```python
@app.route("/admin/books/delete/<int:book_id>", methods=["POST"])
def delete_book(book_id):
    ...
```

```
POST /admin/books/delete/3
                          ↑ この「3」が book_id として関数に渡る
```

- `<int:book_id>` = URLの一部を整数型の変数として受け取る
- 削除系は **POST のみ**（GETだとリンクを踏むだけで消えてしまう）

---

## 各ルートで使うキーオブジェクト

| オブジェクト | 説明 | 使うルート |
|------------|------|----------|
| `request.args` | GETパラメータ（URL の `?` 以降） | `/search` |
| `request.form` | POSTのフォームデータ | `/loan`, `/return`, `/admin/*` |
| `render_template()` | HTMLテンプレートに変数を渡して表示 | 全ルート |
| `redirect()` + `url_for()` | 別のルートへ転送 | POST処理後（PRGパターン） |
| `flash()` | 次の画面に一時メッセージを渡す | POST処理後 |
